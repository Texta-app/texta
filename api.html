Texta API

The Texta API lets you add contacts to your account from any app or automation. It is a simple REST API with a single endpoint. No SDKs, no OAuth flows — just an API key and a POST request.

Overview

The Texta API is designed to be used with automation tools like Zapier. When a new customer fills out a form, makes a purchase, or books an appointment in another app, you can automatically add them to your Texta contact list so they're ready for your next campaign.

⚡
Using Zapier?

Texta is available in the Zapier app directory. Connect your account in seconds without writing any code. Find Texta on Zapier.

All API requests go to the base URL below. The API accepts and returns JSON.

Base URL

https://texta-api.textaops.workers.dev

Authentication

All API requests are authenticated with an API key. You can generate your key in the Texta app under Settings, then Integrations.

Your API key is prefixed with txta_. Keep it secret. Anyone with your key can add contacts to your account. If you suspect it has been compromised, regenerate it immediately from Settings. Regenerating creates a new key and invalidates the old one.

Pass your API key in the request body as the api_key field.

🔒
Keep your API key private

Never share your API key publicly or commit it to version control. Store it in environment variables or a secrets manager.

Add Contact

Adds a contact to your Texta account. If the phone number already exists and the contact is active, the request succeeds with no changes. If the contact previously opted out and you re-add them, they are reactivated.

POST /contacts/add

Request body

Field Type Required Description
api_key string required Your Texta API key, starting with txta_.
phone string required The contact's phone number. Accepts most formats — E.164, domestic US, with or without dashes. Normalized automatically.
first_name string optional Contact's first name. Used for merge tags in messages.
last_name string optional Contact's last name.
email string optional Contact's email address.
tags string optional Comma-separated tags. Example: vip,newsletter,2024
birthday string optional Contact's birthday. Accepts flexible formats such as 1990-05-15, 05/15/1990, or May 15 1990.

Responses

200
Success
Contact was created, already exists, or was reactivated.
400
Bad request
Phone number is missing or could not be parsed.
401
Unauthorized
API key is missing or invalid.
403
Forbidden
Account does not have an active subscription.

A successful response returns a JSON object with a result field indicating what happened:

result valueMeaning
created New contact was added to your account.
exists Phone number already exists and the contact is active. No changes made.
reactivated Contact had previously opted out and has been reactivated.

Example

Request:

{
  "api_key": "txta_your_api_key_here",
  "phone": "312-555-0001",
  "first_name": "Jamie",
  "last_name": "Rivera",
  "email": "jamie@example.com",
  "tags": "vip,spring-promo"
}

Response:

{
  "result": "created",
  "contact_id": "8a3f2c91-4d5e-4b1a-9c7d-2e6f8a0b1c3d"
}
